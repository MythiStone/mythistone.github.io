How this data is collected

Every number on this page comes from real Mythic+ runs rather than theory.

The standout runs, popular team comps, uniquely popular specs and success rates are built from recorded leaderboard runs for {{ dungeon.name.en_US }} across the whole season.

The top routes, most lusted pulls and least played enemies are taken from the actual routes used in the highest-ranked recorded runs, as logged on Keystone.guru. We read the real pulls and cooldowns from those runs, so they show how the best groups genuinely route {{ dungeon.name.en_US }} rather than a planned or theoretical route. Only runs from roughly the last four weeks are included, so this part of the page keeps up with the current meta.

Boss pacing and deaths use the combat logs of the timed runs among them, which record when each boss fight started and ended and when each player died.
