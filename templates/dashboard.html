Spec Performance & Score Metrics

This card holds four views of the same idea, switchable with the tabs. Each plots every spec as a point, with popularity on the y axis (how many runs, or how many characters) and a different performance or score measure on the x axis.

Performance

We look at every run of a spec and award positive points when the key is timed (higher keys earn more) and negative points when it depletes (losing a low key is judged more harshly), then average those points across all runs. It rewards high pushes, balances the penalty for depletes, and stays fair no matter how many runs a spec has.

Top 50 Score

For each spec we take its 50 highest-ranked players from the leaderboards and average their Mythic+ score.

Top 1% Character Score

We average all characters who did a key in the last 2 weeks and whose spec score clears the lowest global top 1% score cutoff (currently about {{ "{:,.0f}".format(top1pct_score) }} {% if top1pct_region %}, in {{ top1pct_region }} {% endif %} taken from Raider.io) and average that score per spec. The Top 1% Score vs Runs tab plots the result against overall popularity, while the Top 1% Score vs Characters tab plots it against how many characters each spec has in the top 1%.
